# GitHub Discussions の運用方針

`routerctl` の GitHub Discussions は、利用者同士の相談とプロダクト改善の
入口です。実装・不具合・レビューの正式な追跡には GitHub Issues と Pull
Requests を使用します。

## カテゴリ

- **Q&A** — コマンド利用、対応環境、導入方法に関する質問と回答。
- **Ideas** — CLI の UX や機能の提案。採用して追跡が必要になった提案は、
  メンテナーが Issue にします。
- **Announcements** — リリース、互換性に関する注意、運用上の告知。投稿は
  メンテナーに限定します。

## 安全とプライバシー

Discussions の投稿は参考情報であり、ファームウェア書込み、RF 送信、規制・
安全・リリースの承認を与えるものではありません。これらに関する判断は、
リポジトリ内の根拠、Issue、Pull Request、および定義済みのレビューゲートで
追跡します。

投稿前に、ログ、設定、スクリーンショットから秘密鍵、トークン、パスワード、
SSID、MAC アドレス、シリアル番号、個人情報などの機密情報を取り除いてください。
完全なフラッシュ内容、EEPROM/MTD ダンプ、未編集の証拠資料も投稿しないでください。

`router-firmware` と `certificateDB` では Discussions を利用しません。前者の
ファームウェア変更、後者の証拠と承認状態は会話スレッドではなく、Issue、Pull
Request、リポジトリ内の証跡で管理します。
