# AI contribution policy

`routerctl` is a Human-AI collaborative project. OpenAI ChatGPT / Codex may assist with design, implementation, documentation, analysis, and tests. AI is not a human reviewer and does not authorize regulatory values, verified evidence, device actions, or public releases.

Changes involving verified-evidence promotion, a regulatory value, device application, or a public release require a named human reviewer. This rule is enforced for the repository's Git review path by `routerctl verify commit`. Repository permissions and any manually created external release remain separate trust boundaries.

When AI materially assisted a change, record exactly:

```text
AI-Assisted-By: OpenAI ChatGPT
```

Do not claim AI assistance, automation, or human review when it did not occur.
